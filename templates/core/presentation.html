01. Executive Summary

Khaja Kham is a comprehensive food delivery ecosystem that integrates advanced data science algorithms with real-time geospatial logistics. The platform is built on three pillars: Predictive Personalization through ML, Transparent Logistics via OpenStreetMap, and Role-Based Efficiency through specialized interfaces for Customers, Riders, and Admins.

03. How the System Works (Algorithms)

1. SMART CART MERGING

Ensures users don't lose their items when they log in. It syncs "Guest Items" with "Account Items".

1 Fetch Guest Session Cart
2 Check for Existing Items in User Account
3 Sum Quantities & Delete Temp Cart

2. SECURE KHALTI VERIFICATION

Guarantees the user actually paid by talking directly to Khalti's secure servers.

1 Get Unique Payment ID (PIDX)
2 Request Status from Khalti Server
3 Mark "PAID" only if Status is "Completed"
